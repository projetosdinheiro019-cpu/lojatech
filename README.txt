NEXORA TECH — protótipo inicial
================================

Como testar:
1. Abra index.html no navegador.
2. Teste os filtros, botão Adicionar, sacola e formulário de checkout.

Importante:
- Este é um protótipo de front-end, não uma loja pronta para receber pagamentos.
- Os produtos e preços são exemplos editáveis; confirme tudo com seus fornecedores.
- A integração real com PateraPay/Pantepay exige documentação oficial da API, credenciais privadas configuradas no servidor e webhook para validar pagamentos.
- Nunca coloque chaves secretas no HTML/JavaScript do navegador.
- Antes de publicar, configure domínio, contato comercial, frete, estoque, políticas, privacidade e termos de compra.
- Não anuncie descontos que não sejam reais; confira preço final, prazo de entrega e disponibilidade.
